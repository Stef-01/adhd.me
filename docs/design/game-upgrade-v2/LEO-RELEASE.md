# Leo's public bedroom — release record

The public `/lives/play/leo-mosquito` route now uses the same interactive bedroom implementation as the lab preview. Players can close the window and park the phone during the encounter, preserve their reading place, choose headphones or quiet, lower the light, and return to the prepared room the following evening. Entry remains direct; the separate Chaos Run swarm remains intact.

Two model corrections accompany promotion. Recovery removes the deadline without deleting scheduled disturbances, so changing the room still matters. The revisit schedules actual insect and phone events instead of immediately inventing prevented-event counts. The model retains independent source controls and preserves the bookmark and room arrangement.

Public-route tests replace obsolete tests of the old standalone renderer; the independent arcade regression is retained. Shared control, fit and text-budget traversals now enact the actual room routine. The lab remains a compatible entry point to the same component.

This releases the previously previewed room and corrects its causal model; it does not complete every gameplay expansion in the v2 plan. No engagement or clinical-efficacy claim follows from technical tests. Further gameplay depth and player review remain in that plan.


## September 21: challenge before strategies

The public route now plays three rounds of 3, 4 and 5 mosquitoes before enabling settling actions. The model also refuses early prop actions, so this order is enforced beyond the UI. Clearing all rounds, overload, the deadline or the explicit recovery control opens the untimed settling scene. Uncaught insects remain during recovery; success is never required to access the bedtime routine. The prepared-room revisit is preserved. The lab remains an exploratory room for testing source controls independently; public sequential play has its own browser suite.

Validation: 20 room model tests and 9 public-sequence browser cases across Chromium, Firefox and WebKit passed. Phone rendering of the post-round controls was inspected. The required challenge, strategy practice and changed revisit sequence is recorded in PLAN.md for every remaining game; those conversions remain staged work, not completed by this Leo release.
